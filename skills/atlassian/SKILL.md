## Jira REST API
Latest definition is stored locally in the examples folder.

Updates are fetched from https://developer.atlassian.com/cloud/jira/platform/rest/v3/intro/
following a link like https://dac-static.atlassian.com/cloud/jira/platform/swagger-v3.v3.json?_v=1.8486.0
(the exact URL ofc depends on version).

When downloading, save it to ~/backlin/git/ai-config/skills/atlassian/examples/
